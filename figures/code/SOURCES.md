# Figure sources for AAAI_2027/main.tex

Every figure in `AAAI_2027/Figures/` and the code that generates it. Run each script from the repo root
(`.`); all use `parents[2]` = repo root, so they also work from
here. **Output is PDF only** (the paper references `.pdf`).

| `fig_lambda.pdf` | **`Figures_code/fig_lambda.py`** (moved here) | `results_llm/lambda_data.json` |
